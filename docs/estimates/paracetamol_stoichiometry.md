# Paracetamol: raw-material factors from stoichiometry (engineering estimate)

Final step (all common Indian routes): acetylation of para-aminophenol (PAP) with acetic anhydride.

C6H7NO (PAP, 109.13 g/mol) + C4H6O3 (acetic anhydride, 102.09 g/mol) -> C8H9NO2 (paracetamol, 151.16 g/mol) + CH3COOH (acetic acid, 60.05 g/mol)

| Input | Calculation | kg per kg paracetamol |
|---|---|---|
| Para-aminophenol | 109.13 / 151.16 | 0.722 |
| Acetic anhydride | 102.09 / 151.16 | 0.675 |

Assumptions and limits:
- 100% yield and 1:1 molar ratio, so these are THEORETICAL MINIMUM figures. Real plants use more (yield losses, excess anhydride).
- Acetic acid is a by-product (0.397 kg/kg), not an input.
- Plants that make their own PAP (e.g. from PNCB) still consume this PAP internally; it is not all purchased.
